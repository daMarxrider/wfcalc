# UI mockups

Static HTML mockups for the new wfcalc UI (issue #100). Each folder is one design direction; none of
them touches `src/web`. Open the `.html` files in a browser, no build needed.

| # | Folder | Idea |
|---|---|---|
| 01 | [`01-panes`](01-panes) | One shell for every tab: numbered Setup steps on the left, sticky run bar and results on the right |
| 02 | [`02-deck`](02-deck) | Nav rail (desktop) / bottom tab bar (phone), setup as collapsible rows that show their value, floating run dock, results below |

Add a new mockup as the next numbered folder and list it here and in the issue.
