# 02 · Deck

Open `index.html` in a browser (no build). All seven tabs; Find has a mockup-only state bar for
Method (Quick / Brute force / Parts) × Result (Done / Running / Nothing found / Error).
Deep links: `index.html?m=parts&r=running#find`.

- **Shell:** left nav rail on desktop, bottom tab bar on phones (Abilities, Riven, Settings under "More").
  A context strip (weapon, target, mods) sits on top of every tab; tapping a chip jumps to Build.
- **Setup as rows:** each topic is one row with its current value ("Limits · 60 capacity · Forma as needed");
  tap to edit. Rare options are collapsed and marked optional. 44 px touch targets.
- **Run dock:** a floating bar with what will run and the one button, always in reach (above the tab bar on phones).
- **Find:** method is a three-way choice at the top; only the fields that method uses are shown.
- **Results:** best build as a sheet (key numbers inline, mod board), then runners-up and warnings.

Not covered: Incarnon, modular parts on Build, sniper zoom, drag to reorder. Stop and the progress
counters are ideas (the engine may not support cancelling or progress).
